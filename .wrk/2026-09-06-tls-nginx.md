## Renewal prerequisite

This certificate currently uses manual DNS validation and DOES NOT renew automatically. Configure a persistent, narrowly scoped DNS integration and complete a renewal dry run before describing renewal as automated. Do not rely on an interactive browser session or store ISPConfig administrator sessions on the web server.

The user has been asked whether an existing ISPConfig DNS API account is available. Keep its credentials under the ignored `.cfg/DNS.txt` when supplied. Verify the actual permission scope supported by ISPConfig before creating any new remote user; do not assume function permissions are limited to one DNS zone.
